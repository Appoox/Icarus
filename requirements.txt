# PyTorch's CPU-only wheels live on a separate index from PyPI. This
# server only ever does lightweight, single-vector inference (search
# query embedding, occasional Article/Literati/Issue/Topic indexing on
# publish) — never batch OCR — so it has no use for a GPU, and pulling
# the default CUDA build would drag in several GB of NVIDIA libraries
# (cuDNN, cuBLAS, NCCL, etc.) that never get touched. The worker machine
# is where GPU acceleration actually pays off — see the GPU note in
# worker/requirements-worker.txt, which deliberately leaves torch
# unpinned so a volunteer with a GPU can install the matching CUDA build
# there instead.
--extra-index-url https://download.pytorch.org/whl/cpu
